# Ali Store — Full Starter
This package includes a working Node.js/Express backend and web store.

Features:
- Admin login
- APK upload
- App name/description/category/version
- Icon upload
- Screenshot upload fields
- Server-side APK storage
- Publish app
- User search/categories
- APK download
- Version field for future updates
- Ratings/reviews
- SQLite database

Default admin:
email: admin@alystore.app
password: AliStore@123

IMPORTANT:
This is a complete starter, not a production Google Play replacement. Before public use, change ADMIN_PASSWORD/JWT_SECRET, use HTTPS, add virus scanning, file-type validation, signed APK verification, rate limiting, backups, moderation and secure object storage.

Run:
1. Install Node.js 18+.
2. In this folder: npm install
3. Start: npm start
4. Open http://localhost:3000
